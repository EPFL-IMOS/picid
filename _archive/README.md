# Archive

Content here was in explicit "archive" or "old" folders and has been moved under `_archive/` mirroring the repo layout.

- **configs/experiment/_archive/** — archived experiment configs (nb1, etth, picasso, etc.)
- **configs/datasource/old/** — old datasource configs
- **configs/transforms/old_but_keep/** — old transform configs kept for reference
- **scripts/** — archived dataset-specific and obsolete scripts (debugging.sh, mzvav, pronostia, xjtu_sy, nb14, unibo, phm20, hsf15, railway, concepts_n_cmapss*, checks)
- **picid/transforms/bearings/old/** — old bearing transform code
- **docs/getting-started/** — archived [Dataset viewer](getting-started/viewer.md) (Panel app for inspecting prepared data)

To use something again: move it back to the same path under the repo root.
