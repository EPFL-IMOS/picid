# Metadata Manifest

Manifest tracking persists provenance through preprocessing.

## Core types

- `MetadataManifest`
- `ManifestEntry`

## What is recorded

- datasource identity/config footprint
- transform sequence provenance
- producer/schema versioning

This metadata is attached to containers and supports reproducibility/audit needs.

See API: [picid.data.data_objects](../../../reference/api/picid_data_data_objects.md)
