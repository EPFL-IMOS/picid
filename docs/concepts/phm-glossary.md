# PHM Glossary

- **RUL (Remaining Useful Life):** estimated time/cycles until failure.
- **SoH (State of Health):** health indicator of degradation state.
- **Feature Engineering:** converting raw sensor streams into model-ready features.
- **Fit-Predict Model:** model with explicit `fit(X, y)` then `predict(X)` workflow.
- **Context Window:** historical segment used as model input.
- **Prediction Horizon (`pred_len`):** number of future steps to predict.
