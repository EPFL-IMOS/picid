# Experiment Generator

This folder contains the Hydra Experiment Generator UI and its data.

## Files

- `index.html` — Generator UI (dropdowns + command builder)
- `config_map.json` — Generated by `scripts/experiment_generator/generate_config_map.py`

## Regenerating config_map.json

From project root:

```bash
uv run python scripts/experiment_generator/generate_config_map.py
```

Run this after adding or changing configs under `configs/`.
