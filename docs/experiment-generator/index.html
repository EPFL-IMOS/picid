How to test the command
  1. Copy the generated command above.
  2. Open a terminal in the project root.
  3. Run uv sync if you haven't already.
  4. Paste and run. Example: uv run python picid/run.py paths=rt_local debug=default experiment=phme20/prognostics/raw/xgboost_fit_predict
How to run and submit to the leaderboard
  1. Copy and run the generated command. This produces a run dir under artifacts/.
  2. Upload the run to Google Drive: uv run python scripts/publish/push_run_to_gdrive.py <run_dir>
  3. Register the Drive link and rebuild the docs site to see results on the leaderboard page.
